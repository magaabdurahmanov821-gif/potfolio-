# Magomed — Portfolio

Одностраничное портфолио на React, TypeScript, Vite, Tailwind CSS и Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

## Структура

```
src/
├── components/         # Переиспользуемый UI и layout
├── data/               # Типизированные данные витрин и проектов
├── features/
│   ├── hero/           # Hero и независимая интерактивная графика
│   └── projects/       # Фильтры, карточки, превью и case-study modal
├── styles/             # Токены, глобальная тема и утилиты
├── App.tsx             # Композиция экранов
└── main.tsx            # Точка входа
```
